02

看核心：一次提问的完整路径

service.py → ask() → coach/agent.py
局势、知识库与相关 Meta 汇合后，交给模型作答。

03

看界面：网页如何调用 Python

webui/app.py → Bridge → static/*.html
pywebview 暴露 Python 方法；主窗口、设置页和悬浮窗使用本地网页。

04

看扩展：替换模型与语音能力

providers.py · audio_providers.py · voice/
统一管理不同服务商与后端，保留业务层的调用方式。

04 RUN IT LOCALLY

从本地运行，到桌面分发。

以下命令在项目根目录运行。首次使用建议先创建并激活 Python 虚拟环境。

POWERSHELL / 项目根目录
配置分开管理
config/settings.yaml 选择服务商、模型与功能参数；API Key 放在 .env。未配置 Key 时返回离线占位回复。
先连接对局数据
安装 GSI 配置并完全重启 Dota 2。默认由本机 127.0.0.1:3000 接收推送；python -m dodoclaw health 可检查接收服务。
打包给其他人使用
scripts/build_app.ps1 构建传统桌面版；scripts/build_webui.ps1 构建新界面预览版。完整打包目录包含运行依赖。

    
框架判断：以本地 Python 服务为核心的模块化桌面应用。
本页基于当前源码与配置模板整理。知识库采用本地关键词检索；LLM、在线语音及数据同步按配置访问外部服务。WebView2 界面在代码中仍标记为原型；真实对局、模型回复质量与语音效果需另行实测。
